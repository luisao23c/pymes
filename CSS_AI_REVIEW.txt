=======================================================================
CONTEXTO DEL PROYECTO
=======================================================================

Este es un constructor de catálogos online para negocios (taquerías, tiendas, etc).
Los usuarios diseñan su catálogo con un editor visual y los clientes ven el catálogo público.

ARQUITECTURA CSS — 3 CAPAS SEPARADAS:

1. DESIGN SYSTEM BASE (material.css)
   - Componentes UI del admin/editor: botones, inputs, cards, chips, badges, switches
   - SOLO se usa en el panel de administración y el editor
   - NO afecta al catálogo público

2. CATÁLOGO PÚBLICO (design.ejs + constructor.ejs + components.ejs)
   - Lo que VEN LOS CLIENTES cuando visitan la tienda
   - design.ejs: variables CSS globales (:root) + estilos de header, chips, cards, search
   - constructor.ejs: estructura del template (header, footer, patrocinados)
   - components.ejs: componentes reutilizables (productos, carruseles, galerías, testimonios, etc)
   - Se renderiza en el SERVIDOR (EJS) y se envía al navegador
   - paintCatalog() en server.js inyecta overrides CSS adicionales

3. EDITOR VISUAL (diseno.ejs)
   - Lo que VE EL USUARIO cuando está diseñando su catálogo
   - Drawer lateral para editar bloques, picker de bloques, galería de imágenes
   - Device frames (iPhone, Samsung, iPad) para previsualizar responsive
   - Canvas con preview del catálogo (pero NO es el mismo render que el público)
   - NO comparte CSS con el catálogo público — son sistemas independientes

REGLAS DUPLICADAS:
   - Hay reglas CSS repetidas entre editor y público (ej: .chip-active, .product-card)
   - Esto es INTENCIONAL: cada sistema se renderiza por separado
   - El editor tiene su propia copia de estilos para el preview del canvas
   - NO se deben "unificar" — si se cambia una, hay que cambiarla en ambos lados

VARIABLES CSS:
   - material.css usa --md-* (Material Design)
   - Catálogo público usa --accent, --bg, --card, --text, etc.
   - Editor usa --wp-* (WordPress-like)
   - Cada sistema tiene sus propias variables

COMO MEJORAR:
   - Si mejoras material.css → afecta solo el admin/editor
   - Si mejoras design.ejs → afecta el catálogo público
   - Si mejoras diseno.ejs → afecta solo el editor visual
   - Si mejoras components.ejs → afecta el catálogo público
   - Las mejoras en UN sistema no afectan a los demás
